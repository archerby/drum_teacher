# 🏙️ Варшава без скуки — генератор прогулок

Мобильное веб-приложение: прогулка по Варшаве под настроение и время, с короткими справками,
безумными (но проверенными) фактами, городскими легендами и скрытыми шедеврами.
Продакшн: **https://guide.upupa.dev** (деплой — см. [DEPLOY.md](DEPLOY.md)).

## Что на входе

| Параметр | Варианты |
|---|---|
| Настроение | 9 настроений (можно два): 🤯 удивите меня, 💘 романтика, 🕯️ задумчиво, 📻 ностальгия по ПНР, 🎨 вдохновение, 🛋️ лень и уют, 🧭 приключение, 🥟 вкусно, 🧸 с детьми — **или своими словами** («хочу странного, но я устал») |
| Время | 30 мин – 5 ч |
| Посидеть по дороге | нет · ☕ кофе · 🍲 поесть · 🌳 лавочка |
| Скрытые шедевры | классика · микс · только тайное |
| Старт | «я здесь» (геолокация) или район |

## Что на выходе

Маршрут на карте и лентой карточек: крючок, короткая справка, 🤯 безумный факт, 👀 что искать глазами,
время и расстояние между точками, привалы, ссылки «как дойти» и весь маршрут в Google Maps.
Точки можно отмечать «был тут», заменять, просить «другой вариант». Маршрут целиком живёт в ссылке —
им можно поделиться. Работает офлайн (PWA), языки: русский, English, polski, українська, беларуская.

**Режим киоска** (`?kiosk`) для музеев и туринфо: крупный интерфейс, заставка с фактами,
автосброс, QR-код «забери маршрут в телефон».

## Как это устроено

```
public/                 статический фронтенд, без сборки и зависимостей
  data/pois.js          51 точка: координаты, берег Вислы, теги тем 0..3, «скрытость», где присесть
  i18n/<lang>.js        тексты интерфейса и справки по точкам (ru — исходник)
  js/moods.js           настроения → веса тем; офлайн-разбор свободного текста (5 языков)
  js/route.js           генератор маршрута
  js/app.js, map.js     интерфейс, карта (Leaflet, лежит в vendor/), киоск
server/server.mjs       Node: статика + /api/mood (Claude: текст настроения → веса тем)
```

Подбор точек устроен как семантический поиск (идея из Semantikora): и настроение, и каждая точка —
векторы в одном пространстве 14 тем (абсурд, история, память, легенды, романтика, виды, природа,
искусство, музыка, ПНР, еда, наука, еврейская Варшава, чудачества). Релевантность — скалярное
произведение плюс поправка на «скрытость» и немного случайности для разнообразия.

Маршрут — задача ориентирования: жадная вставка точек по «ценности на минуту» в бюджет времени
(ходьба 4,5 км/ч × коэффициент петляния 1,3 + время на осмотр + привалы), затем 2-opt и or-opt.
Через Вислу путь идёт только по мостам; переходы длиннее 25 минут запрещены; привал ставится ближе
к середине прогулки (нет обеда рядом — предложит кофе).

## Разработка

```bash
cd server && npm install
npm start                 # http://localhost:8080  (без ключа AI выключен)
npm test                  # генератор маршрутов, парсер настроения, ручка Claude против мок-API
```

Статику можно открыть и без сервера: `python3 -m http.server -d public`.

### Добавить точку

1. `public/data/pois.js` — координаты, `bank`, `area`, `dwell`, `hidden`, `tags`, при желании `rest`/`paid`.
2. `public/i18n/ru.js` → `poi.<id>`: `name`, `hook`, `text`, `fact`, `look` — коротко и только проверенные факты.
3. Те же ключи во всех остальных словарях; `npm test` проверит данные.
