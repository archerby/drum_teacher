# 🥁 Бонго-школа — самоучитель ритмов

Веб-приложение для самостоятельного изучения ритмов на бонго: уроки простым языком, библиотека ритмов со звуком, полиритмы, метроном и тренажёр точности. Работает в браузере на компьютере и телефоне, без установки, без интернета и без регистрации.

## Как запустить

- **Проще всего:** открыть файл `index.html` в браузере (Chrome, Edge, Firefox, Safari).
- **Как приложение на телефоне:** открыть сайт на GitHub Pages — https://archerby.github.io/drum_teacher/ — и выбрать «Добавить на главный экран». После первого открытия приложение работает офлайн.
  Публикация идёт автоматически (`.github/workflows/pages.yml`) при каждом push; в настройках репозитория должно быть *Settings → Pages → Source: GitHub Actions*.
- Локальный сервер (по желанию): `python3 -m http.server` → http://localhost:8000

## Что внутри

| Раздел | Что умеет |
|---|---|
| **Старт** | План обучения из 9 шагов и прогресс в процентах |
| **Уроки** (14) | Устройство бонго и посадка, 6 основных ударов, чтение сетки, пульс и BPM, размеры, восьмые/шестнадцатые, триоли и шаффл, акценты, синкопа, мартильо по шагам, клаве, полиритмия, полиметрия и нечётные размеры, методика занятий и здоровье рук |
| **Ритмы** (40+) | Основы, афро-кубинские (мартильо, тумбао, ча-ча-ча, сон-монтуно, колокол, 6/8), клаве (тресильо, хабанера, синкильо, сон/румба 3-2 и 2-3, босса, 6/8), Бразилия и Карибы (босса-нова, самба, байон, танго, регги, дембоу), поп/рок/фанк/блюз, Ближний Восток (максум, балади, саиди, малфуф, аюб, чифтетелли), нечётные размеры (гемиола, 5/4, 7/8, 9/8, компас солеа) |
| **Плеер** | Цветная сетка с подсветкой текущей клетки, счёт вслух («1 и 2 и»), какой рукой бить, заглушение партий («Играю сам»), отсчёт, щелчок метронома, автоускорение, отметка «Освоено» с рекордом темпа |
| **Редактор** | Создание своих ритмов и изменение готовых: любые размеры, группировки (2+2+3), инструменты; экспорт/импорт текстом, чтобы делиться |
| **Полиритмы** | Любые A:B от 1 до 9, круговая анимация, сетка общего счёта, «результирующий ритм» по рукам, режим полиметра |
| **Метроном** | 20–300 BPM, тап-темп, 1–16 долей, акценты/беззвучные доли, дробления (до секстолей), 4 звука, ускорение-«лестница», пропуски тактов, случайные пропуски, мигание экрана |
| **Тренажёр** | Экранные бонго (касание или клавиши F/J/D/K), замер отклонения каждого удара в мс, процент попаданий, разброс, график, советы, калибровка задержки |

### Обозначения ударов

| Буква | Удар |
|---|---|
| **О** | открытый тон |
| **Ш** | шлепок (слэп) |
| **З** | закрытый (приглушённый) |
| **К** | кончики пальцев |
| **Б** | большой палец |
| **Л** | ладонь (пятка) |

Бледная клетка — тихий удар. Руки: **R** — правая, **L** — левая, **B** — обе.

## Устройство кода

Чистые HTML/CSS/JavaScript без сборки и зависимостей. Все звуки синтезируются через Web Audio API, а планировщик заранее расставляет их по аудио-часам, поэтому ритм остаётся ровным.

```
index.html           — каркас и навигация
css/style.css        — оформление (светлая и тёмная тема, адаптивная вёрстка)
js/audio.js          — синтез бонго, клаве, колокола, шейкера, баса и щелчков
js/transport.js      — точный планировщик шагов
js/store.js          — прогресс и настройки (localStorage)
js/data/rhythms.js   — библиотека ритмов (формат описан в начале файла)
js/data/lessons.js   — тексты уроков и план обучения
js/pages/*.js        — разделы приложения
sw.js                — офлайн-кэш
```

Чтобы добавить ритм, допишите объект в `js/data/rhythms.js`, например:

```js
{
  id: 'my', cat: 'cuban', name: 'Мой ритм', level: 2,
  sig: '4/4', beats: 4, spb: 2, bpm: 90,
  desc: 'Описание', tips: [],
  tracks: [{ i: 'macho', p: 'TPTT TPOT' }, { i: 'hembra', p: '.... ...O' }],
  hands: 'RLRL RLRR',
}
```

Партии, помеченные как «адаптация», — это учебные переложения ритмов других инструментов (конги, сурдо, дарбуки, ударной установки) на бонго.
